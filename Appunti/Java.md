## Multithreading
Java supporta il multithreading a livello di linguaggio (di norma i thread sono implementati a livello di sistema, ma in java è possibile creare programmi multithread in maniera standardizzata, cioè indipendentemente dalla piattaforma).
Per creare un Thread in Java si può creare una classe che deriva da Thread e ridefinisce il metodo run(), oppure implementare nella classe l'interfaccia Runnable (sempre ridefinendo il metodo run()). Nel primo caso, per istanziare un oggetto Thread si istanzia direttamente un oggetto di tipo Thread con il costruttore della nostra classe che estende Thread, mentre nel secondo caso, bisogna prima istanziare l'oggetto Runnable della nostra classe che implementa Runnable e poi istanziare un oggetto Thread della classe Thread passando per parametro il nostro oggetto Runnable.
A differenza di Python, Java non consente l'eredità multipla, quindi di base conviene usare la derivazione da Thread, però se la classe già è coinvolta in un'eredità bisogna usare l'implementazione di Runnnable.
